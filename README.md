# 3주차 실습

3주차 실습 과정에서 만든 문서와 작업 규칙을 정리한 저장소입니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `01_페인포인트.md` | 문제 상황(페인포인트)과 검증 기준 정리 |
| `02_기획안.md` | 기획안과 검증 항목 |
| `CLAUDE.md` | 이 프로젝트에서 AI 작업 시 따를 규칙 |
| `.gitignore` | 공개하지 않을 파일과 폴더를 지정한 설정 |

## 작업 규칙 (CLAUDE.md 요약)

- 문서의 모순이나 오류는 전체 텍스트를 검색해 확인한 뒤에만 지적합니다.
- 검토 결과가 바뀌면 그 결과를 인용한 다른 문서도 함께 맞춥니다.
- 요청받은 범위가 끝나면 남은 항목을 목록으로 보여 주고 마무리할지 묻습니다.
- 작업이 끝나면 완료 항목마다 ✓/✗와 확인 방법을 먼저 보여 줍니다.

## 공개하지 않는 자료

연구 검토 산출물, 개인 메모, 개인정보가 들어간 파일은 `.gitignore`로 제외하고 저장소에 올리지 않습니다.
